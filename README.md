A lightweight, serverless, lightning-fast web application that enables direct browser-to-browser (P2P) file sharing and real-time clipboard text synchronization using WebRTC. 

---

## ✨ Features

* **🔄 Real-Time Clipboard Sync:** Instantly share text, notes, or links between connected devices. Features a vertically resizable text area for seamless typing and viewing.
* **📂 Unlimited File Streaming:** Transfer files of any size directly device-to-device with multi-file support, drag-and-drop zones, and live progress bars.
* **📱 Quick Mobile Pairing:** Automatically generates a 6-digit PIN and a scannable QR code for instant cross-device connections.
* **⚡ Serverless Architecture:** Runs entirely on the client side. No database or heavy backend server required—just drop it onto any standard web hosting provider and go!

---

## 🛠️ Tech Stack

* **Frontend:** Vanilla HTML5, CSS3 (with CSS Variables & Glassmorphism design), JavaScript (ES6+)
* **P2P Networking:** [PeerJS](https://peerjs.com/) (WebRTC wrapper)
* **QR Generation:** [QRCode.js](https://davidshimjs.github.io/qrcodejs/)
